# Conformer CTC Speech Recognition

This project implements an end-to-end Automatic Speech Recognition (ASR) system using a Conformer encoder and CTC loss, trained on the LibriSpeech dataset.

## Dataset
This project is based on the [LibriSpeech ASR dataset](https://huggingface.co/datasets/openslr/librispeech_asr), a large corpus of English audiobooks commonly used for speech recognition research.

## Reference
This project is based on the following paper:

> Gulati, A. et al. (2020). **Conformer: Convolution-augmented Transformer for Speech Recognition.**  
> *Interspeech 2020.* [https://arxiv.org/abs/2005.08100](https://arxiv.org/abs/2005.08100)
